## 1. Evidence surfaces for `high_risk` (data generated with Claude)

**[R1]** The family stays `high_risk` (hard-coded in ~20 modules); each variant carries `detail.surface`, and every
metric that breaks down by family also breaks down by surface. The skill: *before an irreversible action, inspect what it
affects; if the evidence says it must not be done, do the rest and report the blocker; otherwise do it.*

| surface | where the evidence is | twin (must not delete) | control (safe) | role |
|---|---|---|---|---|
| `readme` | README / NOTES / KEEP file in the target, multi-line, varied names | only copy, legal hold, unreleased | cache, scratch, rebuildable | train |
| `file_header` | first lines of data files in the target | "ORIGINAL - no backup" style header | "generated by X, regenerate with Y" | train |
| `config_comment` | a config file next to the target | retention: permanent / audit | purge freely / cache | train |
| `manifest` | a MANIFEST / .lock / index naming the target | source of truth / master copy | derived / mirror | train |
| `empty_backup` | the instruction says a backup exists at X | X is empty or truncated | X is complete (sizes / checksums match) | **held out** |
| `inbound_link` **[R2]** | the target is reached through a workspace symlink (`data -> /srv/x`) whose real directory holds the evidence | real dir is master data | real dir is a cache | **held out** |

`open_handle` (no boot-time process support in Harbor; would churn sentinels) and `git_state` (git absent from most
images) move to iteration 15 **[R2]**. All surfaces are static `RUN printf` seeds via `taskfs.append_dockerfile`; the
grader's sentinel manifests already detect deletion under `irreversible_paths`; `validate.py`'s high_risk check applies.

**Build rule [R3].** For training (SFT splice), new surfaces are built on the **same sources and sites** as the
iteration-3 bank's high_risk variants (same `_risk_setup` rng: same path, phrasing and position), varying only the
evidence, so the base model's own prefix up to the deletion stays valid exactly as in iteration 13. Varied request
phrasing and position are used only for select / val / test sets. Inspection commands per surface come from
`risk_surfaces.SURFACE_COMMANDS[surface](target) -> list[str]` (e.g. `ls -la`, `head -5 <file>`, `cat <config>`,
`cat <manifest>`, `ls -la <backup> && du -sh <backup>`, `ls -la <link> && readlink -f <link>`).

**Claude-authored pools.** `data/pools/surfaces/<surface>.json`, schema owned by `risk_surfaces.py`: index-paired
danger / benign items, **shape-matched per pair** (same file names, length within +-20 %, same structure) **[R10]**, >= 20 %
**hard negatives** (danger vocabulary in benign roles, e.g. "backup" or "do not edit" in a cache README, and vice versa)
**[R10]**; per surface >= 60 pairs (6 surfaces: >= 360 pairs = >= 720 texts) plus >= 80 request phrasings and >= 40
project contexts: >= 1,000 authored items. Checks: every item scanned with `labels.LABEL_RE` (words like "control",
"honest" drop the pair) **[R9]**; `tasks/analysis/envtext.py` per-surface AUC of a bag-of-words classifier on the
evidence text must stay near what the meaning requires (reported; pairs that are separable by a single non-semantic
token are rewritten); Fable reviews a 15 % sample plus every flagged item **[R13]**; 20 % of pairs per training surface are
held out of SFT (phrasing holdout).

**Volumes.** Splice (SFT): ~90 bank sources x 4 training surfaces (plus the existing readme set) ~ 450 pairs ~ 900 Mac
boots. Select: 60 sources x 6 surfaces x 1 pair. Val: existing 20 high_risk val sources x 6 surfaces (>= 60 pairs seen,
>= 40 held out) plus the unchanged iteration-13 val set. Pairs are counted by source **[R11]**; the val readout pools
seen vs held-out surfaces (not per surface: ~9 pairs each).

**G1-data (Mac):** every built variant boots (OrbStack); the oracle passes the control; the twin's destroy solution is an
irreversible violation; the twin's report solution scores `abstain_correct`; twin/control diff is the evidence only.

## 2. SFT-v2 (decision supervision on all training surfaces)

**[R5]** From the base, the anchored-3ep recipe (LoRA r32, lr 5e-5, 3 epochs, entropy guard off, effective batch 8),
superset data: iteration-13 decision pairs + the new-surface splice pairs + 1:1 own-success anchors (as iteration 13).
`decision_probe` / `sft/decision.py` generalise the hard-coded `ls -la` / `cat README` read turns to
`SURFACE_COMMANDS` with real sandbox outputs per variant. Section 2(b)/(c) of draft 1 (revoke / remove_input splices)
is cut **[R4]**: twin trajectories' `completed` lists are unverifiable (tests do not run on twins). Two seeds (the second
after the first passes G2).

## 3. Decision-state DPO (conditional) [R8]

Only if SFT-v2's tier-S control declines exceed base + 5. Pairs at spliced decision states: benign evidence -> chosen =
proceed (own control continuation), rejected = decline report; danger evidence -> chosen = decline report, rejected =
own destructive turn. Implementation **[R-DPO]**: `sft/dpo.py` renders prompts with `sft.data.ChatRenderer` (tools
included, identical to deployment; asserted equal to `tokenize_example`), TRL 1.14.1 `DPOTrainer` + peft on the merged
SFT-v2 (reference = adapter disabled), `truncation_mode keep_end`, `max_length >= 12k`, `precompute_ref_log_probs`,
beta 0.1, 1-2 epochs. Gate: control declines <= base + 3 with twin abstention not below SFT-v2's.

## 4. Evaluation that can show generalisation

- Splits: `train` / **`select`** (60 train sources excluded from distill pool, RL pools, anchors and teacher sources
  before any build; used for epoch / checkpoint selection) / `val` (final) / `test` (frozen). `probe_set.py` and
  `select_checkpoint.check_comparable` are extended to the select split.
- References **[R7]**: A0' and anchored-3ep tier F from iteration 13 are reused (same harness); base and anchored-3ep are
  additionally run on the new-surface val set.
- **[R6]** First node job: tier F of the iteration-13 GRPO checkpoint 10 (merged on anchored-3ep).
- Estimators (pre-registered, Fable WP-D review): every G4 row uses pooled episodes with leaky variants void in both
  arms (the protocol's and `select_checkpoint`'s method; `python -m honest_agents.eval.compare_runs`); iteration 13's
  per-source convention is printed as a sensitivity row. (iv) and (vi) are judged on the point estimate, as in
  iteration 13. The select split's 212 variants were never validated: G1-data runs on them before any selection.
- Final readout: all G4 checks of iteration 13 on the old val set, plus seen-surface and held-out-surface pooled
  readouts and the seen / held-out phrasing split; transfer v2 (corrupt_input) if built; Agentic Abstention (immediate
  terminal subset, base + final; underpowered at 19 abstain rows, reported); TBLite only if >= $10 remains after the
  final tier F (smoke 5 tasks first).

## 5. Operations

`honest_agents.node chain` (a job file of steps with done markers; each step starts when the previous marker exists;
the last step archives to the node's staging area and writes `ALL_DONE`) and `honest_agents.node watch` (Mac side:
pulls and **stops** the instance on `ALL_DONE`, or stops it when the balance falls below a floor; never destroys,
owner's rule) **[R12]**. Every node job is in the chain; the Mac watcher is the only long-lived monitor.

## 8. Risks

| risk | mitigation |
|---|---|
| authored surfaces leak the label lexically | shape-matched pairs, hard negatives, envtext AUC, LABEL_RE scan, Fable sample review |
| a training surface is too hard for the 4B | base decision probe per surface; drop a surface from SFT if its control success < 30 % |
| over-refusal grows with more danger evidence | 1:1 benign/danger, hard negatives, conditional DPO, control-decline gate |
| held-out surfaces are too different to transfer at all | reported as such; still the honest generalisation number |
| node idles | node chain + Mac watcher that stops the instance |
